# XBoard Bot Matrix API 文档

> Legacy/reference only. Vanguard 主线已经收口到 HMAC 签名的
> `/api/v1/...` 协议，详见 `docs/vanguard-mainline-architecture.md`。
> 本文档中的 Bearer `/api/bot/...` 接口仅作为历史 bot-matrix
> 对照资料，不再作为新 Worker 或后台对接 XBoard 的实现依据。

## 概述

本文档描述 XBoard Telegram Bot 矩阵与 XBoard 主系统之间的 API 接口规范。

**基础 URL**: `http://localhost:8080/api`（生产环境替换为实际域名）

**认证方式**: Bearer Token

```
Authorization: Bearer {XBOARD_API_KEY}
```

---

## 通用响应格式

### 成功响应

```json
{
  "success": true,
  "message": "操作成功",
  "data": { ... }
}
```

### 错误响应

```json
{
  "success": false,
  "message": "错误信息"
}
```

## 用户相关 API

### 1. 创建试用账号

创建新的试用账号并返回订阅链接。

**请求**

```
POST /api/bot/users/create-trial
```

**请求体**

```json
{
  "tg_uid": 123456789,
  "username": "testuser",
  "validity_hours": 24,
  "traffic_gb": 50
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| tg_uid | int | 是 | Telegram 用户 ID |
| username | string | 否 | 用户名 |
| validity_hours | int | 否 | 有效期（小时），默认 24 |
| traffic_gb | int | 否 | 流量（GB），默认 50 |

**响应**

```json
{
  "success": true,
  "message": "试用账号创建成功",
  "data": {
    "user_id": 1,
    "email": "trial_123456789@xboard.local",
    "password": "Abc123!@#xyz",
    "expires_at": "2026-05-18 20:00:00",
    "traffic_gb": 50
  }
}
```

---

### 2. 绑定 Telegram

将 Telegram 账号绑定到现有 XBoard 账号。

**请求**

```
POST /api/bot/users/bind-tg
```

**请求体**

```json
{
  "tg_uid": 123456789,
  "api_key": "your_xboard_api_key"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| tg_uid | int | 是 | Telegram 用户 ID |
| api_key | string | 是 | XBoard API 密钥 |

**响应**

```json
{
  "success": true,
  "message": "绑定成功",
  "data": {
    "user_id": 1,
    "email": "user@example.com",
    "username": "testuser"
  }
}
```

| 参数 | 类型 | 说明 |

```json
{
  "success": true,
  "data": {
    "user_id": 1,
    "email": "user@example.com",
    "username": "testuser",
    "plan_id": 1,
    "plan_name": "VIP 月套餐",

```

### 4. 增加用户流量

为用户增加流量（用于签到奖励等）。

**请求**

```
POST /api/bot/users/{tgUid}/add-traffic
```

**路径参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| tgUid | int | Telegram 用户 ID |

**请求体**

```json
{
  "traffic_mb": 512,
  "reason": "每日签到奖励"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| traffic_mb | int | 是 | 增加的流量（MB） |
| reason | string | 否 | 增加原因 |

**响应**

```json
{
  "success": true,
  "message": "流量添加成功",
  "data": {
    "added_mb": 512,
    "new_total_gb": 55.0
  }
}
```

---

### 5. 获取订阅链接

获取用户的订阅链接（支持多协议）。

**请求**

```
GET /api/bot/users/{userId}/subscription-link?protocol=clash,v2ray,surge
```

**路径参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| userId | int | XBoard 用户 ID |

**查询参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| protocol | string | 协议类型，逗号分隔，默认 all |

**响应**

```json
{
  "success": true,
  "data": {
    "clash": "https://xboard.com/api/v1/client/subscribe?token=xxx",
    "v2ray": "https://xboard.com/api/v1/client/subscribe?token=xxx",
    "surge": "https://xboard.com/api/v1/client/subscribe?token=xxx"
  }
}
```

## 订单相关 API

### 7. 获取未支付订单

获取创建后超过指定时间的未支付订单。

**请求**

```
GET /api/bot/orders/unpaid?timeout_minutes=30
```

**查询参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| timeout_minutes | int | 超时时间（分钟），默认 30 |

**响应**

```json
{
  "success": true,
  "data": [
    {
      "id": "order_123456",
      "tg_uid": 123456789,
      "plan_id": 1,
      "plan_name": "VIP 月套餐",
      "amount": "99.00",
      "created_at": "2026-05-17 19:00:00"
    }
  ]
}
```

---

### 8. 创建优惠券

为指定订单创建限时折扣券。

**请求**

```
POST /api/bot/orders/create-coupon
```

**请求体**

```json
{
  "order_id": "order_123456",
  "discount_percent": 20,
  "validity_hours": 2
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| order_id | string | 是 | 订单 ID |
| discount_percent | int | 是 | 折扣百分比（1-100） |
| validity_hours | int | 否 | 有效期（小时），默认 2 |

**响应**

```json
{
  "success": true,
  "data": {
    "code": "SAVE20ABC123",
    "discount": 20,
    "validity_hours": 2,
    "expires_at": "2026-05-17 22:00:00"
  }
}
```

---

### 9. 应用优惠券

将优惠券应用到指定订单。

**请求**

```
POST /api/bot/orders/{orderId}/apply-coupon
```

**路径参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| orderId | string | 订单 ID |

**请求体**

```json
{
  "coupon_code": "SAVE20ABC123"
}
```

**响应**

```json
{
  "success": true,
  "message": "优惠券已应用",
  "data": {
    "original_amount": "99.00",
    "discount": "19.80",
    "final_amount": "79.20"
  }
}
```

## 错误码

| 错误码 | 说明 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未提供认证令牌 |
| 403 | 认证令牌无效 |
| 404 | 资源不存在 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |

## Webhook 回调（可选）

如需主动推送通知，可配置 Webhook URL：

```
POST /api/bot/webhook
```

**推送事件**

- `user.created` - 新用户注册
- `order.created` - 新订单创建
- `order.paid` - 订单支付成功
- `traffic.low` - 流量不足预警
