## 结果

- 在单个 Vanguard 业务库事务中删除 10 条 TrustSource 旧代理（ID 16–25），创建 5 条新代理（ID 26–30），更新 5 个启用的用户账号的静态绑定。
- 每条新代理均为 `residential`、`socks5`、`evomi`；账号使用 `proxy_mode=static`，每个代理只绑定一个用户账号。
- 从生产后端使用用户提供的配置进行预检；提交后再次读取数据库中实际保存的凭据进行测试。两轮测试均确认 5 个实际出口 IP 相符且互不相同，Telegram API 均返回 HTTP 200。

- 后端本地 `/health` 及公开站点 `https://vanguard.pipenai.xyz/health` 均返回 `healthy`。
