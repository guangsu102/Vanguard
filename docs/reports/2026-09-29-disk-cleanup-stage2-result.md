## 范围与执行方式

- 清理范围固定为用户批准的 `stage2-paused-images.csv` 中 269 个唯一完整 SHA256 ID，不增加新候选，也不包含之前已单独删除的公共 Playwright 镜像。
- 在执行前再次扫描 8,047 个配置/部署/回滚文本文件及 66 个离线镜像归档，核对完整和缩写镜像 ID、全部运行/停止容器引用。
- 由子镜像到父镜像逐项执行 `docker image rm --no-prune <完整镜像ID>`；未使用 `--force`、image prune、system prune 或 volume prune。
- 每次删除前重新检查全部容器的镜像引用。Docker 拒绝删除的对象记录原因并跳过。
- 187 个删除 ID 全部属于获批清单，库存差异与命令成功记录逐项一致；没有额外删除其他镜像。
- 82 个跳过对象均由 Docker 报告存在 dependent child images。进一步检查镜像依赖图，82 个全部能追溯到获批清单外的保留子镜像，因此继续保留，没有强制处理。
