- 同账号、客户端和群上下文内，合并重叠消息 ID，复用同次读取的消息、角色及 root；明确回复数为 0 时省掉空回复查询，未知数量保持未知。

- 充分先例快路径在人数、在线、当前权限、作者身份、警告完整性及其他必要门禁齐备后停止无关历史/规则采集。一般禁广告规则仍可由合格普通成员先例获得 trial。
- 未读取的规则/历史标记 `NOT_EVALUATED`，不写为无禁令或完整覆盖；需要完整规则/负面历史的分支回原流程，未评估材料不能充当完整 AI 缓存。
- 在两条正文裁剪路径前捕获相关事件。有界摄取队列：128 项、总计 8 MiB（含在途）、单项 256 KiB；磁盘操作串行移出监听线程。满队列、写失败和恢复缺口回原读取，不推进 SDK 协议水位。
- 成熟原帖、必要作者身份、警告及旧规则锚点仍现场核验；推送缓存只复用精确账号/群/加入关系/内容版本及短时 SDK 连续性已证明的事件。
- 新增管理员只读观测：首次取证、继续取证、成熟、事件复验、AI、预算、技术及补证等待；实际读取、预留和非全量样本分别展示。复用现有账本及最多 200×2 个原样本，不新增无界指标存储。
