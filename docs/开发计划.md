- 人工审核：敏感词入库前必须经过审核工作流

- [x] KeywordGenerator 关键词生成
- [x] AICopywriter 文案优化
- [x] 单元测试（79个测试用例全部通过）

**内容审核架构**：

```
消息到达 ──► KeywordEngine 敏感词匹配（实时，低成本）
                    │
                    ▼ 命中敏感词
              违规处理（禁言/删除/警告）

══════════════════════════════════════════

后台：敏感词库维护（手动触发，AI辅助）

违规样本积累 ──► AI批量分析 ──► 候选敏感词 ──► Web后台审核 ──► 入库
```

**人工审核工作流**：
1. 管理员提交违规样本
2. AI分析样本，生成候选敏感词
3. 候选词进入审核队列（PENDING）
4. Web后台审核：批准（APPROVED）或拒绝（DISCARDED）
5. 批准后词库自动更新
