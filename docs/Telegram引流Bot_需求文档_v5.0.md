## 一、项目概述

### 1.1 项目背景

通过 Telegram 群组引流，配合 XBoard 平台实现用户转化，构建自动化营销体系。

### 1.2 项目目标

- **曝光目标**：每日触达用户 1000+ 人次
- **注册目标**：注册转化率 ≥ 70%
- **付费目标**：付费转化率 ≥ 60%
- **ROI 目标**：≥ 1000%

### 1.3 核心价值

- 降低获客成本至 ¥5/人以下
- 实现 7×24 小时自动化运营
- 支持多账号矩阵运营

### 3.2 用户状态详细定义

| 状态 | 定义 | 触发条件 | 运营策略 |
|------|------|----------|----------|
| **NEW** | 新注册用户 | 注册完成但未领取试用 | 发放试用券，引导体验 |
| **PENDING** | 待转化（试用期） | 已领取试用或注册3天内 | 引导转化，发放优惠 |
| **ACTIVE** | 活跃付费用户 | 完成首次付费 | 维护关系，续费引导 |
| **SILENT** | 沉默用户 | 试用/付费到期后7天内未付费 | 召回流程，发放优惠 |
| **CHURNED** | 流失用户 | 到期后14天未付费或主动注销 | 放弃标记 |
| **BLOCKED** | 被拉黑用户 | 用户主动拉黑 | 停止触达 |

### 4.2 群组分级体系

#### 4.2.1 分级评分维度

群组根据以下维度进行评分（满分100分）：

| 维度 | 权重 | 评分因素 |
|------|------|----------|
| **群规管控** | 30% | 有无群规、是否禁止广告、是否禁止外链 |
| **管理员态度** | 25% | 友好/中立/敌对、是否有警告/踢出历史 |
| **Bot历史** | 20% | 被踢次数、消息成功率、警告次数 |
| **转化效果** | 15% | 点击率、注册率 |
| **群活跃度** | 10% | 日均消息数、成员流动频率 |

#### 4.2.2 等级定义

| 等级 | 分数区间 | 特征描述 | 操作策略 |
|------|----------|----------|----------|
| **A级（高价值）** | 70-100分 | 无严格群规，管理员友好，历史无惩罚 | 可发广告、可@用户、可高频发言 |
| **B级（中价值）** | 50-69分 | 有群规但不严格，管理员中立 | 禁止硬广、可软推、限次发言 |
| **C级（低价值）** | 30-49分 | 群规严格或历史有惩罚 | 仅@触发时回复、禁止主动引导 |

#### 4.2.3 A级群操作权限

| 权限项 | 值 | 说明 |
|--------|-----|------|
| 可发送广告消息 | 是 | 支持硬广 |
| 可主动@用户 | 是 | 可@任意用户 |
| 可分享外链 | 是 | 无限制 |
| 可主动私聊触达 | 是 | 关键词触发即可私聊 |
| 群消息每日限额 | N（可配置） | 默认10条 |
| 群消息间隔 | N秒（可配置） | 默认60秒 |
| 私聊消息间隔 | 5秒 | 固定5秒 |
| 好评率控制 | 是 | 需监控被踢/警告率 |

#### 4.2.4 B级群操作权限

| 权限项 | 值 | 说明 |
|--------|-----|------|
| 可发送广告消息 | 否 | 禁止硬广告 |
| 可聊天式软推广 | 是 | 自然聊天方式 |
| 可@用户 | 否 | 禁止主动@ |
| 关键词触发后私聊 | 是 | 关键词匹配即可私聊 |
| 群消息每日限额 | N（可配置） | 默认5条 |
| 群消息间隔 | N秒（可配置） | 默认180秒 |
| 私聊消息间隔 | 5秒 | 固定5秒 |

#### 4.2.5 C级群操作权限

| 权限项 | 值 | 说明 |
|--------|-----|------|
| 主动发言 | 否 | 禁止任何主动发言 |
| 用户@触发回复 | 是 | 仅用户@时回复 |
| 私聊引导 | 是 | 用户主动后触发 |
| 可分享外链 | 否 | 禁止分享 |
| 群消息每日限额 | N（可配置） | 默认2条 |
| 私聊消息间隔 | 5秒 | 固定5秒 |

### 4.3 群组管控信息采集

#### 4.3.1 采集维度

| 类别 | 采集项 |
|------|--------|
| **基本信息** | 群名称、群ID、用户名、群人数、群类型 |
| **群规管控** | 是否有群规、是否禁止广告、是否禁止外链、管理员态度 |
| **历史行为** | 是否被踢出、发言成功率、被警告次数 |
| **转化效果** | 点击率、注册率、用户互动率 |
| **成员特征** | 用户质量、活跃度、目标用户比例 |

#### 4.3.2 管理员态度判定

| 态度 | 判定条件 |
|------|----------|
| **友好** | 30天内无踢出、无警告 |
| **中立** | 有少量警告但无踢出 |
| **严格** | 有踢出记录或警告>2次 |
| **敌对** | 30天内踢出>3次 |

### 4.4 动态等级调整

#### 4.4.1 自动降级规则

| 触发条件 | 调整动作 |
|----------|----------|
| 7天内被踢出1次 | 降1级 |
| 连续7天成功率<50% | 降1级 |
| 收到管理员警告 | 降1级 |
| 30天内被踢出3次 | 降为C级（最低） |

**注意**：不设D级，C级为最低等级

#### 4.4.2 自动升级规则

| 触发条件 | 调整动作 |
|----------|----------|
| 30天内无警告 | 升0.5级分 |
| 14天内成功率>90% | 升1级分 |
| 转化率>5%持续14天 | 升1级 |

#### 4.4.3 调整限制

- 24小时内只能调整1次
- 7天内调整需分数差≥10分

### 4.5 群组去重机制

| 去重方式 | 说明 |
|----------|------|
| **ID精确匹配** | 同一群ID不重复添加 |
| **Username匹配** | 同一用户名不重复添加 |
| **标题模糊匹配** | 相似标题（编辑距离<3）不重复添加 |
| **关键词溯源** | 记录添加时使用的关键词 |

## 五、关键词管理体系

### 5.1 关键词分类

| 类型 | 定义 | 示例 |
|------|------|------|
| **需求类** | 用户主动寻找服务 | VPN、翻墙、机场、节点、梯子 |
| **咨询类** | 用户有问题想了解 | 怎么翻墙、节点怎么用、安全吗 |
| **价格类** | 用户考虑购买 | 便宜VPN、哪里买、最便宜 |
| **竞品类** | 竞品相关 | XX机场、XXVPN、XX加速器 |

### 5.2 AI关键词生成机制

#### 5.2.1 生成规则

| 规则 | 说明 |
|------|------|
| **按需生成** | 待处理关键词<10个时触发 |
| **冷却期** | 两次生成间隔≥30分钟 |
| **日限额** | 每日最多生成5次 |
| **批量大小** | 每次生成20个关键词 |

#### 5.2.2 AI生成上下文

生成时参考以下信息：
- 最近成功的关键词（效果好）
- 效果好的群类型
- 竞品相关关键词

#### 5.2.3 关键词状态

| 状态 | 说明 |
|------|------|
| **待处理** | 已生成，等待评估 |
| **已添加** | 评估通过，加入搜索队列 |
| **执行中** | 正在使用该关键词搜索 |
| **已完成** | 本轮搜索完成 |
| **废弃** | 效果差或重复，标记废弃 |

### 5.3 关键词管理页面

#### 5.3.1 列表功能

| 功能 | 说明 |

| 批量操作 | 批量启用/禁用/删除 |

#### 5.3.2 配置项

| 配置项 | 说明 |
|------|------|
| 触发方式 | 消息内容包含关键词（支持模糊匹配） |
| 响应动作 | 自动回复、触发私聊、记录日志 |
| 防骚扰 | 同一群/用户触发间隔≥30分钟 |

## 六、用户问询处理

### 6.1 触发来源

| 来源 | 说明 |
|------|------|
| **关键词触发** | 消息包含配置关键词 |
| **@Bot触发** | 用户@Bot账号 |
| **私聊触发** | 用户主动私聊 |
| **指令触发** | 用户发送特定指令如 /help |

### 6.2 意图分类

| 意图类型 | 触发关键词 | 响应方式 |
|----------|------------|----------|
| **购买意向** | 买、购买、付费、价格、推荐、哪个好 | 私聊+优惠推送 |
| **咨询意向** | 怎么、如何、是什么、能不能 | 群内回复 |
| **对比意向** | 对比、比较、区别 | 私聊 |
| **投诉意向** | 不好、垃圾、退款、跑路、投诉 | 人工介入 |
| **闲聊** | 谢谢、好的、ok | 简单回复 |

### 6.3 响应模式

| 模式 | 适用场景 | 响应方式 |
|------|----------|----------|
| **私聊响应** | 购买意向、对比意向、用户主动 | AI对话或模板回复 |
| **群内响应** | 咨询意向、简单问题 | 简短回复 |
| **人工响应** | 投诉意向、复杂问题 | 转人工队列 |

### 6.4 私聊触发机制

#### 6.4.1 触发条件

| 触发时机 | 说明 |
|----------|------|
| ☑ 用户主动@Bot | 用户主动互动 |
| ☑ 用户询问价格/购买 | 高意向信号 |
| ☑ 用户表达强烈兴趣 | 多次互动 |
| ☑ 用户触发关键词 | 配置的关键词被触发 |
| ☐ 用户询问后5分钟无回复 | 可选配置 |

#### 6.4.2 防骚扰设置

| 限制项 | 值 |
|--------|-----|
| 同一用户触发间隔 | ≥30分钟 |
| 每日同一用户最多触发 | 3次 |

### 6.5 响应内容生成

#### 6.5.1 生成方式

| 方式 | 说明 | 比例 |
|------|------|------|
| **AI生成** | 调用AI生成个性化回复 | 70% |
| **模板回复** | 使用预设模板 | 30% |

#### 6.5.2 AI回复要求

- 专业但不生硬，像朋友推荐
- 不要夸大宣传，实话实说
- 适当引导但不强迫
- 回复简洁，100字以内
- 如询问价格可提"新人有优惠"
- 遇到投诉先安抚再了解

### 7.1 发送渠道优先级

| 优先级 | 渠道 | 说明 |
|--------|------|------|
| 1 | Telegram 私信 | 优先使用 |



### 7.2 发送时间规则

| 规则 | 说明 |
|------|------|

### 7.3 重试机制

| 次数 | 等待时间 | 说明 |
|------|----------|------|
| 第1次 | 5分钟 | 首次失败后 |
| 第2次 | 15分钟 | 第二次失败后 |
| 第3次 | 1小时 | 第三次失败后 |
| 3次失败 | - | 进入人工处理队列 |

### 7.4 用户行为响应

| 用户行为 | 系统响应 |
|----------|----------|
| 回复"退订" | 立即停止非必要消息 |
| 回复"不需要" | 减少该用户消息频率 |
| 用户拉黑 | 停止所有消息，标记BLOCKED |
| 用户投诉 | 立即停止并告警 |

### 7.5 消息类型

| 类型 | 占比 | 说明 |
|------|------|------|
| **互动型** | 40% | 模拟用户提问，如"求推荐" |
| **分享型** | 30% | 分享使用经验，如"用的还不错" |
| **引导型** | 20% | 带链接推广，如"需要可以试试" |
| **答疑型** | 10% | 回答他人问题 |

## 十、异常处理

### 10.1 用户异常行为处理

| 异常场景 | 检测方式 | 处理方案 |
|----------|----------|----------|
| 反复注册/注销 | 30天内注册>3次，telegram号 | 标记羊毛党，封禁用户，收回优惠卷 |
| 注册后不活跃 | 注册后7天无任何操作 | 降低消息频率，延长引导周期 |
| 领取优惠不购买 | 领取后14天未使用 | 增加召回频次，发放更大折扣 |
| 用户主动注销 | 收到注销事件 | 停止消息，保留数据，优惠卷作废 |
| 用户拉黑Bot | 收到block事件 | 停止消息，标记BLOCKED |
| 用户投诉 | 收到举报/投诉 | 立即停止触达，人工处理 |

### 10.2 系统异常处理

| 异常场景 | 降级策略 | 恢复策略 |
|----------|----------|----------|
| Telegram API不可用 | 暂停Telegram操作 | API恢复后自动重试 |
| XBoard API不可用 | 暂停优惠卷发放 | API恢复后补发 |
| 数据库连接失败 | 使用缓存，暂停统计写入 | 数据库恢复后同步 |
| 消息队列积压 | 降低发送速率 | 峰值后消化，扩容消费者 |
