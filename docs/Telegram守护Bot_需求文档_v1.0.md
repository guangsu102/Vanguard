## 一、项目概述

### 1.1 项目背景

社群守护Bot用于管理自建群组，负责内容审核、竞品拦截、用户行为管理和节点播报等功能。

### 1.2 核心目标

- **拦截目标**：竞品广告/外链拦截率 ≥ 99%
- **响应速度**：违规消息识别响应时间 ≤ 3秒
- **用户满意度**：误杀率 ≤ 1%

## 三、内容审核

### 3.1 审核维度

| 审核类型 | 说明 | 优先级 |
|----------|------|--------|
| **关键词审核** | 匹配预设关键词 | P0 |
| **链接审核** | 检测可疑外链 | P0 |
| **图片审核** | 检测推广图片 | P1 |
| **频率审核** | 检测刷屏行为 | P1 |
| **账号审核** | 新账号/可疑账号检测 | P2 |

### 3.2 审核动作

| 动作 | 说明 | 触发条件 |
|------|------|----------|
| **警告** | 发送警告消息 | 首次违规 |

| **禁言** | 临时禁言用户 | 累计警告≥2次 |
| **封禁** | 永久踢出用户 | 累计警告≥3次 |

## 四、竞品拦截

### 4.1 竞品关键词分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **品牌词** | 具体竞品名称 | XX机场、XXVPN、XX加速器 |
| **通用词** | 行业通用词 | 机场、节点、梯子、VPN |
| **价格词** | 促销相关 | 便宜、折扣、优惠、免费 |
| **邀请词** | 邀请/aff相关 | 邀请码、aff、返利 |
| **链接词** | 外链相关 | t.me/、bit.ly/、.vip/ |

### 4.2 关键词规则

#### 4.2.1 关键词配置

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 关键词 | 匹配文本 | XX机场 |
| 匹配模式 | 精确/模糊/正则 | 模糊 |
| 违规等级 | 严重/一般 | 严重 |
| 动作 | 警告/禁言/封禁 | 封禁 |
| 群组范围 | 全局/指定群组 | 全局 |

#### 4.2.2 默认关键词库

```
# 竞品品牌词（严重）
- XX机场
- XXVPN
- XX加速器
- [其他竞品名称...]

# 通用推广词（一般）
- 机场|节点|梯子|VPN
- 翻墙|科学上网
- 节点出售|卖节点
- 便宜机场|低价节点

# 外链格式（严重）
- t\.me/\w+
- (aff|邀请).*t\.me
- 邀请码.*[a-zA-Z]

# 可疑域名（一般）
- \.vip$
- \.xyz$
- \.top$
- bit\.ly
- goo\.gl
```

### 4.3 域名黑名单

| 类型 | 说明 | 示例 |
|------|------|------|
| **竞品域名** | 直接封禁 | *. competitor1.com |
| **短链接** | 短链接服务 | bit.ly, t.ly, goo.gl |
| **可疑域名** | 高风险后缀 | .vip, .xyz, .top |

### 4.4 白名单机制

| 白名单类型 | 说明 | 示例 |
|------------|------|------|
| **用户白名单** | 特定用户不受拦截 | 管理员、老用户 |
| **群组白名单** | 特定群组不审核 | 官方公告群 |
| **内容白名单** | 特定内容不受限 | 官方公告链接 |
| **时间白名单** | 特定时段不拦截 | 活动时间 |

## 五、用户行为管理

### 5.1 用户状态

| 状态 | 定义 | 说明 |
|------|------|------|
| **NORMAL** | 正常用户 | 无违规记录 |
| **WARNED** | 警告用户 | 收到过警告 |
| **MUTED** | 禁言用户 | 被临时禁言 |
| **BANNED** | 封禁用户 | 被永久封禁 |

### 5.2 警告机制

#### 5.2.1 警告等级

| 等级 | 触发条件 | 禁言时长 | 累计规则 |
|------|----------|----------|----------|
| **警告1级** | 首次违规（一般） | 无 | 可清除 |
| **警告2级** | 二次违规 或 首次严重违规 | 10分钟 | 累计 |
| **警告3级** | 三次违规 或 二次严重违规 | 1小时 | 累计 |
| **封禁** | 四次违规 或 三次严重违规 | 永久 | - |

#### 5.2.2 警告清除规则

| 规则 | 说明 |
|------|------|
| 自动清除 | 警告后7天无违规自动清除 |
| 手动清除 | 管理员手动清除 |
| 部分清除 | 只清除低等级警告 |

### 5.3 禁言机制

#### 5.3.1 禁言类型

| 类型 | 时长 | 说明 |
|------|------|------|
| **临时禁言** | 10分钟/1小时/24小时 | 自动解除 |
| **周期禁言** | 每天限时 | 如每晚22:00-08:00禁言 |
| **永久禁言** | 永久 | 需要手动解除 |

#### 5.3.2 禁言权限

| 配置项 | 说明 |
|--------|------|
| Bot权限 | Bot需要有群组禁言权限 |
| 管理员豁免 | 管理员不受禁言限制 |
| 白名单豁免 | 白名单用户不受禁言 |

### 5.4 封禁机制

#### 5.4.1 封禁类型

| 类型 | 说明 | 解除方式 |
|------|------|----------|
| **临时封禁** | 一定时间后自动解除 | 自动 |
| **永久封禁** | 永不解除 | 管理员手动 |
| **设备封禁** | 封禁设备/账号 | 永久 |

#### 5.4.2 封禁执行动作

| 动作 | 说明 |
|------|------|
| 踢出群组 | 将用户移出群 |
| 加入黑名单 | 禁止再次加入 |
| 撤回历史消息 | 删除该用户近期消息 |
| 通知用户 | 私聊告知封禁原因 |
